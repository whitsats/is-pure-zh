# I"s Pure 简体中文汉化补丁 v7

PS2 游戏《I"s Pure》（SLPM-66570，桂正和原作《I"s》改编）的简体中文汉化补丁。

本补丁基于百度贴吧 IS 吧与 QQ 群 IS汉化讨论的前辈们 2011–2023 年的人工翻译成果，在此基础上完成全剧本重译、菜单与系统文本汉化，2026 年 11 月封版 v7。

> 仅供学习交流。请使用自己合法拥有的游戏原盘打补丁，支持正版。

## 使用方法

需要自己准备 PS2 游戏原盘 ISO（`game-original.iso`）。

1. 下载本仓库的完整补丁包 `I-s-Pure-最终汉化结果-20261113-v7.zip`，解压。
2. 把 `game-original.iso` 放到打盘脚本默认目录（`~/workspace/is-pure/`，Windows 下为用户目录下的 `workspace\is-pure\`）。
3. 在 `打盘/` 目录运行：

   ```
   python3 build_v7.py etc-v6.afs mac-v6.afs init-v5-lazy.bin SLPM_665.70-patched.elf game-v7.iso
   ```

4. 打完校验 md5 应为 `49dd66a1980d4f81aea51069d35299df`（Windows：`certutil -hashfile game-v7.iso MD5`）。
5. 用 PCSX2 加载 `game-v7.iso` 游玩（需自备 PS2 BIOS）。
