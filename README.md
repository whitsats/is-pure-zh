# I"s Pure 简体中文汉化补丁 v7.2

PS2 游戏《I"s Pure》（SLPM-66570，桂正和原作《I"s》改编）的简体中文汉化补丁。

本补丁基于百度贴吧 IS 吧与 QQ 群 IS汉化讨论的前辈们 2011–2023 年的人工翻译成果，在此基础上完成全剧本重译、菜单与系统文本汉化，2026 年 11 月封版 v7。v7.1 修字库残影、标点过大与系统文本被 NUL 截断；v7.2 修字形纵向落位（「一」被抬高）。两版都只修显示缺陷，不改文本内容。

> 仅供学习交流。请使用自己合法拥有的游戏原盘打补丁，支持正版。

## 版本说明

### v7.2（2026-11-13，修复更新）

只修字形纵向落位，文本与 v7.1 相同：

- **「一」这类字被抬高**：v7.1 用 Pillow `textbbox` 的高度做纵向定位，但 `textbbox` 返回的是**布局框**而不是**墨迹框**——20 像素的「一」它返回高度 9，真实墨迹只有 2 行，于是「一」被顶到格子上部（实测第 7–8 行，原盘是 11–12 行），人名条「一贵」的「一」和「贵」不在同一条水平线上。另外 v7.1 按旧字形的墨迹底对齐，而新字 20 像素、原字 24 像素，对齐「底」等于把整行下压 2–3 行。
- **修法**：三类字（汉字 20 像素、标点 18 像素、全角拉丁 18 像素）一律画在字体自身的自然基线上，只保留「不许出 24×24 格」的最小夹取。原盘字库本来就按自然位置画字，所以这样落位才对得上。

1518 个可比汉字的墨迹中心与原盘同一汉字的差：

| 版本 | 平均偏移 | 范围 | 超出 ±1.5 行 | 「一」所在行 |
| --- | --- | --- | --- | --- |
| v7 | +2.81 | +1.5 … +4.0 | 1517 / 1518 | 13–14 |
| v7.1 | +2.29 | −4.0 … +3.5 | 1330 / 1518 | **7–8** |
| **v7.2** | **+0.22** | **−1.0 … +1.0** | **0 / 1518** | **11–12**（与原盘一致） |

原理、修法与可复现的四步命令见 [`修复/说明.md`](修复/说明.md)。

### v7.1（2026-11-13，修复更新）

只修显示缺陷，文本与 v7 相同：

- **字库残影（发糊）**：字库里每个字占两位像素，v7 写新字形前只清掉其中一位，原版字形的另一半留在字模里和新字形叠加，表现为章节标题、菜单里未汉化的全角英文与数字重影。v7.1 写入前两位一起清空，重影消失，已汉化的中文与 v7 逐像素一致。
- **标点过大**：v7 保留原版约 24 像素满格的标点，比 20 像素正文大一圈。v7.1 把剧本实际用到的 25 个全角标点改为 18 像素方正粗圆。
- **系统文本被 NUL 截断**（影响面最大）：v7 替换中文时按原日文行长度逐行补 `0x00`，字符串中间出现 NUL，而游戏文本解释器遇到第一个 NUL 就结束，导致多行提示只显示第一行、所有「是／否」确认框只有问句没有选项、复制／粘贴／删除／写入 这类菜单只显示第一项。ELF 里共 116 条记录受影响，v7.1 全部修好。

原理、修法与可复现的四步命令见 [`修复/说明.md`](修复/说明.md)。

### v7（2026-11-13，封版）

- 对白：全剧本 16 章 24,876 行全中文。IS01–06 沿用前辈 2016 年译文；IS07–16 为 2026 年全量重译。
- 菜单：跳章选单（SHORTCUT）章节标题中文；右栏只剩「第X话起」。
- 系统文本：ELF 内 657 条系统文本中文（「系统」因字库缺「统」字，写作「设定数据／主菜单」）。
- 字库：新增 13 字（乒 乓 官 蒡 壶 熊 泰 迪 谊 珊 瑚 霞 —），安全字集 3,064 字。

## 使用方法

需要自己准备 PS2 游戏原盘 ISO（`game-original.iso`）。两种方式任选：

### 方式一：一键打盘（推荐，无需 Python）

1. 到 [Releases](https://github.com/whitsats/is-pure-zh/releases) 下载 `I-s-Pure-oneclick-patcher-v7.2.zip`，解压。
2. 把 `game-original.iso` 拖到 `I-s-Pure-汉化一键打盘-v7.2.exe` 上（或双击 EXE 选择原盘）。
3. 程序在同目录生成 `<原盘名>-汉化版-v7.2.iso`，校验 MD5 应为 `7b91e356a7e879d9e7ec6f99a2885d66`。
4. 用 PCSX2 加载它游玩（需自备 PS2 BIOS）。

### 方式二：脚本打盘

1. 到 [Releases](https://github.com/whitsats/is-pure-zh/releases) 下载 `I-s-Pure-final-20261113-v7.2.zip`（完整补丁包），解压。
2. 把 `game-original.iso` 放到打盘脚本默认目录（`~/workspace/is-pure/`，Windows 下为用户目录下的 `workspace\is-pure\`）。
3. 在 `打盘/` 目录运行：

   ```
   python3 build_v7.py etc-v6.afs mac-v6.afs init-v5-lazy.bin SLPM_665.70-patched.elf game-v7.2.iso
   ```

4. 打完校验 md5 应为 `7b91e356a7e879d9e7ec6f99a2885d66`（Windows：`certutil -hashfile game-v7.2.iso MD5`）。

## 文件说明

- `对照/`：16 份中日对照 TSV（24,876 行），翻译底本（仓库内直接提供）。
- `打盘/`：打盘脚本（`build_v7.py`，另附 `build_iso.py`、`build_iso_v7.py` 供参考）。打盘用的二进制文件在完整补丁包内。
- `修复/`：显示缺陷修复的源码与格式笔记，见 [`修复/说明.md`](修复/说明.md)。
  - `系统文本/修复截断消息.py`：修 116 条被 NUL 截断的记录（自带从原盘取原版 ELF 的步骤）。
  - `系统文本/分析截断消息.py`：诊断工具，逐条打印中日原文、现状与修复结果。
  - `字库/制作粗圆修复字库.py`：重写字形（清两位残留 + 标点 18 像素 + 纵向自然基线落位）。
  - `字库/替换字库.py`：把新字库压回 ETC.AFS。
- `一键打盘/`：一键打盘工具源码（`patcher.py` + PyInstaller spec + 使用说明），即 Release 里那个 EXE。
- `工具/`：**自定义字库打盘**，把任意 TTF/OTF（或一份现成字库）换成盘上的字库，
  用来换字体风格或调字号；带图形界面。见 [`工具/说明.md`](工具/说明.md)。
