# PS2 汉化流程

汉化包在原盘镜像上替换资源，保留原机播放和执行逻辑。只处理字库、译文与系统文本时，不需要 WebGAL 或安卓移植工程。

1. 准备合法持有的未修改 `game-original.iso`。本机项目放在 `素材/PS2原盘/`；也可以提供原打盘脚本的 `~/workspace/is-pure/` 路径。
2. 在 [对照](../对照/) 校订中日文本。带有旧版作者原始工程和码表时，用 [烘焙文本](../打盘/烘焙文本.py) 的 `--检` 核对地址、编码、槽位长度和控制符边界。
3. 如果改动用字，按 [修复说明](../修复/说明.md) 重建字库和 ETC.AFS。系统文本修复单独核对多行提示和菜单条目。
4. 使用 [一键打盘](../一键打盘/) 或 [打盘脚本](../打盘/build_v7.py) 生成新镜像。保留输入原盘，并核对输出哈希、剧情台词、选单和存读档。

现有译文评审的过程记录在 [审查简报](../对照/审查简报/)。PS2 素材提取、运行时验证和移植相关源码由独立的 [is-pure-port](https://github.com/whitsats/is-pure-port) 维护。
