# 自定义字库打盘

把**任意 TTF/OTF/TTC 字体**做成游戏字库，打进已经汉化好的 I's Pure 镜像里。
用来换风格（粗圆 → 其他字体）、调字号，或者直接用一份现成的字库文件。

只换字库，**不改剧情文本**；输入镜像不会被修改。

## 图形界面

```
python 工具/自定义字库打盘.py
```

不给任何参数就会开图形界面：选输入镜像 → 选自定义字体（或现成字库）→ 选输出路径 →
「只看预览」先看图，满意了再「开始打盘」。

## 命令行

```bash
# 换字体出盘
python 工具/自定义字库打盘.py --盘 game-v7.1.iso \
      --字体 方正粗圆_GBK.ttf --输出 out.iso

# 合集字体（.ttc/.otc）：用 --字体编号 选面。宋体在 simsun.ttc 里，编号 0=SimSun
python 工具/自定义字库打盘.py --盘 game-v7.1.iso \
      --字体 C:/Windows/Fonts/simsun.ttc --字体编号 0 \
      --汉字字号 22 --标点字号 20 --拉丁字号 20 --输出 out.iso

# 先只看效果，不出盘（预览图与输出同名 .png，或 --预览 指定路径）
python 工具/自定义字库打盘.py --盘 game-v7.1.iso --字体 方正粗圆_GBK.ttf --预览 效果.png

# 直接用现成字库：.lzss 压缩态，或 1200128 字节的解压态 FONT00
python 工具/自定义字库打盘.py --盘 game-v7.1.iso \
      --字库 字体研究/_verify3/font/FONT00-粗圆.lzss --输出 out.iso

# 只导出字库文件，不出盘
python 工具/自定义字库打盘.py --盘 game-v7.1.iso \
      --字体 方正粗圆_GBK.ttf --导出字库 新字库.lzss
```

| 参数 | 说明 |
| --- | --- |
| `--盘` | 输入镜像。必须是**已经汉化过**的盘 |
| `--字体` | 自定义字体 `.ttf/.otf/.ttc`（与 `--字库` 二选一） |
| `--字体编号` | `.ttc/.otc` 合集里的第几个字体，默认 0 |
| `--字库` | 现成字库（与 `--字体` 二选一） |
| `--输出` | 输出镜像路径 |
| `--字库源` | 改用这份解压态 FONT00 作槽位与字距基准，默认用盘上那份 |
| `--汉字字号` | 默认 20 |
| `--标点字号` | 默认 18 |
| `--拉丁字号` | 默认 18 |
| `--纵向微调` | 整行上下平移几个像素，默认 0，正=下移 |
| `--预览` | 生成预览图；不给路径则与输出同名 |
| `--导出字库` | 额外把生成的字库写到这个路径 |

只给 `--预览` / `--导出字库` 而不给 `--输出`，就只出图/出字库，不动镜像。

## 它做了什么

1. 从镜像的固定位置（LBA 159082，槽位 17,889,280 字节）取出 `ETC.AFS`，
   解析出第 4 号条目 `FONT00.FOP`（LZSS 压缩态）并解压。
   这份字库同时充当**槽位与字距的基准**：哪个字码占哪个槽、每个槽的左右边界
   （`0x1e + index*2` 处的两张表）都沿用盘上的原样，所以换字体不会让字的位置整体跑掉。
2. 用给定字体重新渲染字码表（`修复/字库/字码频率证据.json`，2508 个字码；
   实测替换 2446 个，跳过 74 个非汉字/标点）。
   规则与 `修复/字库/制作粗圆修复字库.py` **完全一致**（本工具直接调用它，不复制逻辑）：
   - 旧字形残留两位一起清（修重影/发虚）
   - 标点与全角拉丁用较小字号（修标点过大）
   - 三类字一律画在字体自身的自然基线上（修纵向落位，例如「一」被抬高）
3. 把新字库 LZSS 压缩后替换回 `ETC.AFS`，按 2048 字节对齐重新分配空间，同步修正条目表与元数据。
4. 把 `ETC.AFS` 写回镜像的固定槽位，其余扇区原样照抄，最后回读校验。

因为只动这一处，镜像的目录记录、主程序、其他归档都逐字节不变，
**输出的盘与输入盘只在 `ETC.AFS` 槽位内有差异**（`字体研究/_diff_iso.py` 可以自己验）。

## 换字体后字会不会跑位

横向不会。每个字的左右边界来自**盘上那份字库**的字宽表，不是重新算的，
所以换字体只改字形、不改字距。

横向居中用的是：

```python
center = (原字墨迹左 + 原字墨迹右 + 1) / 2
left = round(max(metric_left, min(center - width/2, metric_right + 1 - width, 24 - width)))
```

`center` 取自 `--字库源`（默认＝盘上那份字库）的**同一个字**的墨迹中心。
当 `center - width/2` 正好落在 `.5` 上时，取整方向会随基准字库差一个像素。
实测（脚本 `字体研究/_对比两份字库.py`）：拿 v7.1 的盘当输入、用默认基准，
与仓库里那份 v7.3 字库相比，写入的 **2446 个字形里有 57 个横向差 1 像素，
纵向 0 个，形状 0 个**（0.7%，在 24×24 的格子里就是挪一个像素）。

要**逐字节复现**仓库那份字库，就显式指定同样的基准：

```bash
python 工具/自定义字库打盘.py --盘 game-v7.1.iso --字体 方正粗圆_GBK.ttf \
      --字库源 打盘/FONT00-v6.FOP.bin --输出 out.iso
```

（这份字体本身不在仓库里，需要自备。）

纵向按字体自己的设计走。三个字号都画在字体自身的自然基线上，规则与 v7.3 一致。
但**不同字体在自己的字身里放字的位置不一样**，而游戏把 24×24 的格子画在固定位置，
所以换字体可能整行偏移。实测：

| 字体 | 「一」在字身里的高度 | 整行相对原盘 |
| --- | --- | --- |
| 方正粗圆（v7.3） | 59% | ≈ 0 |
| 宋体 SimSun | 42% | 高约 1 行，字号 20 时「一」偏高 2–3 行 |

（宋体那个数字在 44 像素下同样成立，所以不是它内嵌的 12–17 像素点阵位图造成的，
是宋体本身的设计。）

工具每次会打印「纵向落位」一行，给出新字形与**输入盘上现有字**的行中心差；
差 1 行以上时提示可用的 `--纵向微调` 值。注意这个基准是「输入盘上的字」——
v7.1 的盘自己就比原盘低约 2 行，差值里含有这一部分。

## 换字体后字太细

游戏字库是 **1-bit** 的（每个像素只分「亮/不亮」，没有灰度），所以抗锯齿渲染后
覆盖率落在阈值以下的像素会直接消失。笔画细的字体——典型是宋体这类衬线体——
在 20 像素下就会显得断断续续。

工具每次打印「笔画粗细」一行（每个汉字平均点亮多少像素），细到不足盘上现有字的
一半就会提示。实测：

| 字库 | 每个汉字平均点亮像素 | 结果 |
| --- | --- | --- |
| 原盘日文字库 | 256 | — |
| 方正粗圆 20px（v7.3） | 191 | 正常 |
| 黑体 20px | 119 | 正常 |
| 宋体 22px | 100 | 可用，仍明显比粗圆细 |
| 宋体 20px | 65 | **偏细，工具会提示** |

粗体/黑体类字体在 20 像素下就能用；宋体这类要 22 起。

## 用宋体跑通过（2026-11-13）

```bash
python 工具/自定义字库打盘.py --盘 字体研究/_verify3/v7.3.iso \
      --字体 C:/Windows/Fonts/simsun.ttc --字体编号 0 \
      --汉字字号 22 --标点字号 20 --拉丁字号 20 --纵向微调 1 \
      --输出 song22.iso
```

替换 2446 个字形，字库压缩后 631,012 字节（粗圆是 630,852），回读校验通过，
镜像大小不变、只有 ETC.AFS 槽位有差异。已在 PCSX2 里启动确认：
对白（「伊织是高中话剧团的成员。」「我喜欢通过角」）与人名条都正常显示，
字形明显是宋体，位置正确。

顺带记一下换字体过程中暴露、并已修掉的三件事：

1. `.ttc` 合集字体直接报错——`fontTools` 读合集必须给 `fontNumber`，
   Pillow 必须给 `index`。→ 加 `--字体编号`，并在工具里列出合集里有哪几个面。
2. 宋体 20 像素太细，1-bit 化以后笔画断断续续。→ 加「笔画粗细」提示。
3. 宋体整行比粗圆高约 2 行（它的「一」画在字身 42% 处）。→ 加「纵向落位」提示
   与 `--纵向微调`。

## 注意

- 输入盘必须是**已经汉化过**的盘。拿原版日文盘来换字库没有意义 ——
  日文正文会用到被覆写的槽位。
- 仓库不附带字体文件。
- 依赖：Python 3 的 `numpy`、`Pillow`、`fontTools`（图形界面还需要标准库
  `tkinter`，Windows 版自带）。
