# MAC 剧本文本指针：初步观察

日期：2026-11-13。本文是对游戏原始数据的只读调查记录，供原生移植研究使用。它确认了几条真实剧本文本的引用关系，**没有破解分支、画面、语音和其他控制指令**。

## 样本与发现

- 输入：`E:\Entertainment\IS\game-original.iso` 中的 `MAC.AFS`。档案在光盘镜像中从 LBA `192346`（字节偏移 `393924608`）开始；第 0 项按现有游戏 LZSS 解压，得到 **6096 字节**的脚本数据。
- 第 0 项中，在以下偏移观察到小端字节序的 `60 00 00 00`；紧接的 4 字节按小端整数解析，恰好指向该条目的日文文本。该关系与 `对照\IS01-中日对照.tsv` 开场行一致。

| `60 00 00 00` 的偏移 | 紧随的 4 字节（小端指针） | 指向位置 | 文本开头 |
|---|---|---|---|
| `0x0088` | `a0 08 00 00` | `0x08A0` | 伊織ちゃんは高校の演劇部に所属している。 |
| `0x0094` | `cd 08 00 00` | `0x08CD` | おとなしい感じの彼女が、舞台の上では… |
| `0x00DC` | `12 09 00 00` | `0x0912` | 伊織「いろんな人を疑似体験するのが楽しいの」 |
| `0x00E8` | `43 09 00 00` | `0x0943` | 伊織「アイドルとか歌手には興味がありません… |
| `0x0114` | `9e 09 00 00` | `0x099E` | 水着姿の伊織ちゃんがそう語る。 |

同样方式观察到后续至少 15 条候选文本引用。文本末尾有 `%K%P` 和 NUL 等字节；仅凭外观**不能断言**这些控制符分别是什么意思，也不能断言 `0x60` 的完整语义、指令长度、参数类型或所有出现位置都是独立的有效指令。

对 `game-v7.4.iso` 的第 0 项作同一位置检查，候选标记与上述指针值保持一致；文本内容使用汉化盘的自定义字库映射，不能直接按 CP932 当成中文读取。现成的 `打盘\烘焙文本.py` 可依据原作者项目文件的文本偏移和原文校验进行定点替换，但它不是能解释剧情控制流的解析器。

## 最小复现

在 `E:\Entertainment\IS` 项目根目录，以已安装的 Python 运行以下代码。它只读原盘，并复用 `移植验证\extract_bg.py` 中的解压函数：

```python
from pathlib import Path
import struct
import sys

sys.path.insert(0, str(Path("移植验证").resolve()))
from extract_bg import unpack

with Path("game-original.iso").open("rb") as f:
    base = 192346 * 2048
    f.seek(base + 8)  # AFS 第 0 项的偏移与压缩长度
    offset, length = struct.unpack("<II", f.read(8))
    f.seek(base + offset)
    raw = unpack(f.read(length))

assert len(raw) == 6096
for position in (0x88, 0x94, 0xDC, 0xE8, 0x114):
    assert raw[position:position + 4] == b"\x60\x00\x00\x00"
    target = struct.unpack_from("<I", raw, position + 4)[0]
    assert target < len(raw)
    text = raw[target:target + 128].split(b"\x00", 1)[0]
    print(f"{position:#06x} -> {target:#06x}: {text.decode('cp932')}")
```

`128` 是本次样本打印上限，不是已经验证的字符串最大长度或通用解析边界。复现后应分别确认目标处确实有 NUL，不能把超过上限的截断文本当作完整字符串。

## 仍需攻克

需要建立可验证的指令边界与参数模型，结合 PCSX2 运行时观察或逆向执行器，定位图片加载、人物立绘、语音播放、分支条件、跳转、等待等命令，再选一段含选项和语音的真实剧情与原游戏逐项对照。文本表的先后顺序不等于游戏实际的执行顺序，现阶段不能据此制作完整剧情或声称全游戏能够自动转换。
