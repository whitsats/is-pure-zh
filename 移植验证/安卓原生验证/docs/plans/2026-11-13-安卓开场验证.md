# 安卓开场验证 Implementation Plan

**Goal:** 构建无需 PS2 模拟器、可安装的 Android 原生开场场景验证版。

**Architecture:** 一个原生 Activity 使用 Canvas 绘制实际提取的事件 CG 与中文对话，触摸推进并保存当前页；资源及字幕仅限可追溯的开场样本，不臆造剧情分支或声音对应关系。

**Tech Stack:** Android Java SDK、aapt、javac、d8、zipalign、apksigner；不依赖第三方框架或 PS2 模拟器。

1. 在独立目录准备 Android 清单、图像、来源可追溯的开场字幕和原生 Activity。
2. 制作离线构建脚本，生成、对齐、测试签名并验证 APK；不修改已有模拟器、镜像或存档。
3. 检查 APK 清单、打包内容、签名；若本机 Android 测试设备或开发模拟器可用，再验证安装、触摸推进和界面。
4. 明确标注当前内容只是开场验证，记录未实现的完整剧情、分支、语音与存档等部分及进一步验证需要。
