# 外部方案调研与立绘像素偏离排查报告（2026-11-14）

## 一、 网上已有工具与同厂方案调研

**核心目标**：查明开源社区与外部工具链中是否存在针对 PS2《I"s Pure》（SLPM-66570）、开发商 Regista 或发行商 Takara Tomy 的成熟提取方案。

### 1. 社区主要工具核查（事实记录）
- **punk7890/PS2-Visual-Novel-Tool**：
  - 本地参考库中存在源码文件 `ps2-vn-tool-reference/src/scenes/regista.gd`，但主程序 `main.gd` 中该模块被全局注释禁用（`#REGISTA, # temp value`）。
  - `regista.gd` 第 86~87 行注释显示作者处理 `image_type == 5` 时标注 `#don't know yet. tile size is 128.`，表明作者同样卡在 PS2 瓦片重排与未知格式上，属于未完工的弃置半成品。
  - 工具内收录的 Regista 挂名作品实测：
    - **《12Riven》**：底层走 `Kid.gd`（KID 社老引擎，读取 `.DAT`/`.BGD`/`.LST`），与本作无技术关联。
    - **《鹡鸰女神》（Sekirei）**：底层走 `HuneX.gd`（Alchemist 采用的 HuneX 通用商业引擎），与本作自研切片无关。
- **QuickBMS / XeNTaX / ZenHAX**：
  - 官方库与社区归档中均无针对《I"s Pure》或 Regista 自研 PS2 引擎的公开 `.bms` 脚本。
- **发行商维度（Takara Tomy）**：
  - Takara Tomy 在 PS2 上主要发售漫改动作与儿童向游戏（如《火影忍者》、《变形金刚》等），无同引擎文字冒险作品。

### 2. 调研结论
全网目前**无现成可用**的专属提取工具。当前仓库推导出的“`(x, y, w, h)` 部件表 + 连续全局块号（tilewrap）”已是目前逆向深入度最高的结果，外部无现成作业可直接复用。

## 二、 立绘“肉眼可见像素偏离”根因剖析

针对用户与实测反馈的人设立绘（如下颌线、颈部、发际轮廓）在拼合后存在的阶梯状错位与锯齿，综合分析技术根因如下：

1. **粗粒度网格硬对齐（32 像素步长）**：
   - 当前离线解码器对部件坐标全部按 `x = u8 * 32, y = u8 * 32` 计算。
   - 部件表记录中 `+4` 偏移处的 `u16`（恒为 2？）及头部其他未明字段，尚未排除是否存在细粒度偏移（Sub-tile offset）或微调控制参数。若存在像素级微调偏移而硬按 32 整数倍摆放，斜线跨部件边界时必然产生 1~2 像素台阶。
2. **PS2 GS 渲染采样特性（Half-pixel offset 与双线性滤波）**：
   - PS2 GS 光栅化精灵（SPRITE）时使用定点数 UV，存在经典的半像素偏移机制。
   - 游戏运行时对精灵贴图启用了双线性滤波（Bilinear Filtering）。离线直接采用最近邻（Nearest-Neighbor）离散拼接，会把原画在低分辨率下的天然边缘断差暴露出来。
3. **Alpha 预乘与边缘融合**：
   - PS2 原始 Alpha 为 0~128，直接线性拉伸至 255 若缺乏预乘处理，半透明过渡边缘在特定背景下容易呈现硬边锯齿。

## 三、 获取 Ground Truth（地面真值）的运行时 Dump 方案

为彻底摆脱离线黑盒盲调参数，建议通过以下运行时抓取方案获取游戏引擎自身的真实渲染结果与顶点数据：

### 方案 1：RenderDoc 截帧（最推荐，兼具“完美成品”与“真实坐标”）
- **后端设置**：PCSX2 渲染器配置为 **Vulkan**（或 Direct3D 11/12）。
- **执行方式**：通过 RenderDoc 的 `Launch Application` 启动 `pcsx2.exe`，在立绘完整显示的帧按下 `F12` 截帧。
- **产出价值**：
  1. **Draw Call 图像**：在 Event 列表单步跟踪到立绘绘制调用，直接导出当前已合成无错位的 Render Target 无损 PNG。
  2. **Mesh 顶点数据**：查看该 Draw Call 传给 GPU 的精确浮点顶点坐标 $(X, Y, U, V)$，与离线脚本的 `(x, y)` 直接差分，即可实证那 1~2 像素究竟是固定偏移、采样滤波还是来自表内未知字段。

### 方案 2：Ninja Ripper 2.x（批量抓取当前帧网格与纹理）
- **后端设置**：PCSX2 渲染器配置为 **Direct3D 11**。
- **执行方式**：注入 PCSX2，在游戏内触发 Rip，导出当前显卡管线内的所有 Mesh 和纹理贴图。导入 Blender 可获得自然闭合的立绘拼合网格。

### 方案 3：PCSX2 原生 GS Dump (`Shift + F8`)
- **执行方式**：游戏中立绘出现时按 `Shift + F8` 保存 `.gs` 记录。
- **使用方式**：使用 PCSX2 GS Debugger 单步查看 PRIM 绘图指令与 GIF 打包数据，核对真实投射坐标。
