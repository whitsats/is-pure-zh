## 已验证的内容

- 本机 FFmpeg 8.0.1 包含 `adpcm_adx` 解码器。本次从 `game-original.iso` 读取 `VOICE.AFS` 的 0、100 号和 `SE.AFS` 的 0、2 号原始条目，使用 FFmpeg 的 `adx` 输入和 PCM 输出，四项均成功解码。
- 这四项的 FFmpeg PCM 与现有 `移植验证/背景抽样验证/adx_decode.py` 所产生的 WAV **明显不同**。例如 VOICE 0：FFmpeg 峰值 13449、RMS 2198；旧 WAV 峰值 10710、RMS 801。SE 0：FFmpeg 峰值 17708、RMS 2099；旧 WAV 峰值 1225、RMS 90。
- 旧脚本当前仅按量化值乘 scale 解码，没有计算 ADX 的预测项。仅有波形连续不等于声音正确，旧版 WAV 不能作为可靠译码结果；FFmpeg 是更可信的候选，但仍需与模拟器实录试听对照，不能仅凭两者不一致就声称完全正确。
- VOICE 0 头部声明每声道 127236 个采样，FFmpeg 输出 127264 个采样，尾部多出的 28 个可能属于编码帧填充。正式导出应按头部声明的有效采样数截断，并验证末尾。
- 原盘中名为 `BGM.AFS` 的条目已检出 TIM2 图片，不能仅凭名字当作背景音乐。音乐的真实位置及播放规则尚未确定。

## 无需写入文件的复验

从 `E:\Entertainment\IS` 工作目录运行以下 Python（需要现成的 `numpy` 和 PATH 中的 `ffmpeg`），它从原盘读取两个语音和两个音效条目，让 FFmpeg 通过管道输出 PCM，再与原有 WAV 做统计比较；不会修改镜像或输出文件：

```python
from pathlib import Path
import struct
import subprocess
import wave
import numpy as np

iso = Path('game-original.iso')
old_dir = Path('移植验证/背景抽样验证/audio')
items = [('VOICE', 696072192, 0), ('VOICE', 696072192, 100),
         ('SE', 395005952, 0), ('SE', 395005952, 2)]

with iso.open('rb') as f:
    for name, base, index in items:
        f.seek(base + 8 + index * 8)
        offset, length = struct.unpack('<II', f.read(8))
        f.seek(base + offset)
        blob = f.read(length)
        result = subprocess.run(
            ['ffmpeg', '-hide_banner', '-loglevel', 'error', '-f', 'adx',
             '-i', 'pipe:0', '-f', 's16le', '-acodec', 'pcm_s16le', 'pipe:1'],
            input=blob, stdout=subprocess.PIPE, stderr=subprocess.PIPE, check=True)
        new = np.frombuffer(result.stdout, dtype='<i2').astype(np.int32)
        with wave.open(str(old_dir / f'{name}_{index:05}.wav'), 'rb') as wav:
            old = np.frombuffer(wav.readframes(wav.getnframes()), dtype='<i2').astype(np.int32)
        n = min(len(old), len(new))
        rms = lambda a: float(np.sqrt(np.mean(a.astype(np.float64) ** 2)))
        print(name, index, 'samples', len(new),
              'peak new/old', np.max(np.abs(new[:n])), np.max(np.abs(old[:n])),
              'RMS new/old', round(rms(new[:n]), 2), round(rms(old[:n]), 2),
              'mean absolute difference', round(float(np.mean(np.abs(new[:n] - old[:n]))), 2))
```
